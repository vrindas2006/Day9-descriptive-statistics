# Day 9 – Descriptive Statistics Primer

## Overview

This project is part of my Data Analytics Internship Task – Day 9.

The objective of this task is to perform descriptive statistical analysis on the Titanic dataset using Python and Pandas.

## Objectives

- Calculate mean, median, and mode
- Calculate standard deviation
- Calculate percentiles
- Calculate Interquartile Range (IQR)
- Analyze skewness
- Compare mean and median
- Visualize the distribution of passenger fares using a histogram
- Summarize the statistical results

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

## Dataset

The analysis was performed using the **Titanic dataset**.

The following numerical variables were selected:

- Pclass
- Age
- SibSp
- Parch
- Fare

## Analysis Performed

### 1. Mean
Calculated the average value of each numerical variable.

### 2. Median
Calculated the middle value of each variable.

### 3. Mode
Identified the most frequently occurring value.

### 4. Standard Deviation
Measured the variation of observations around the mean.

### 5. Percentiles
Calculated the 25th, 50th, and 75th percentiles.

### 6. Interquartile Range (IQR)
Calculated the spread of the middle 50% of the observations.

### 7. Skewness
Analyzed the direction and degree of asymmetry in the distributions.

### 8. Visualization
Created a histogram to visualize the distribution of passenger fares.

## Key Findings

- The mean age of passengers was approximately **29.70 years**, while the median age was **28 years**.
- The most common passenger class was **3rd class**.
- The median values of `SibSp` and `Parch` were both **0**.
- `Fare` showed high variability with a standard deviation of approximately **49.69**.
- `Fare` had a skewness value of approximately **4.79**, indicating strong positive/right skewness.
- The histogram confirmed that most passengers paid relatively lower fares, while a smaller number paid substantially higher fares.

## Conclusion

Descriptive statistics helped identify the central tendency, variability, and distribution of the numerical variables in the Titanic dataset.

The analysis showed that the `Fare` variable is highly right-skewed, mainly because a small number of passengers paid considerably higher fares than most passengers.

This task provided practical experience in using Pandas and Matplotlib for basic statistical analysis and data visualization.
